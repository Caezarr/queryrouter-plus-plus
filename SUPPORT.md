# Support

## Getting Help

QueryRouter++ is an open-source LLM routing framework. For self-hosters and users, support is available through the following channels:

### Bug Reports & Feature Requests

For bugs, unexpected behavior, or feature requests, please [open an issue](https://github.com/Caezarr/queryrouter-plus-plus/issues) on GitHub. Include:
- QueryRouter++ version
- Python version
- Steps to reproduce (for bugs)
- Expected vs. actual behavior

### Security Vulnerabilities

**Do not open public issues for security vulnerabilities.**

Please report security issues privately by following the [Security Policy](SECURITY.md).
